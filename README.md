# REMNANT Android updates

Este repositório distribui APKs assinados, o manifesto público de atualização e a página de apresentação do REMNANT. O código-fonte do aplicativo e do projeto web permanece privado; `docs` contém somente a exportação pública da landing page.

Conheça e baixe o app: https://jotadev21.github.io/remnant-updates/

O domínio gratuito do GitHub Student Pack será conectado depois de ser resgatado. O workflow Pages publica a pasta `docs`; o download consulta `latest.json` e aponta para a release oficial. Fotos pessoais e saves não fazem parte deste site.
